# Local separation model

`demucs-htdemucs.json` records the official model source and the measured full SHA256. The full digest is pinned in `ai4music_core.separation.models.DEFAULT_MODEL` and checked before every load. Upstream publishes the first eight digest characters in its checkpoint filename, not a separate full digest. Do not substitute unverified files: the official checkpoint uses Python pickle internally.

The production engine installs Demucs 4.0.1, Torch 2.5.1 and TorchAudio 2.5.1 from the explicit PyTorch **CPU** wheel index on Windows/Linux. Python 3.12 is the workspace runtime. This avoids downloading CUDA dependencies. The provider will select CUDA only when the installed Torch runtime actually reports an available CUDA device; the standard CPU bundle runs on CPU, including on the AMD Radeon 780M host. Torch 2.5.1 preserves the checkpoint-loading behavior expected by Demucs 4.0.1; upgrades must verify the official fixed-hash pickle loading path rather than enabling arbitrary pickle files.

The API process imports no Torch code during startup or capability discovery. A hidden child process performs inference, uses four CPU threads at most, and reports completed model segments rather than estimated timer progress. `shifts=0` selects a deterministic single-pass baseline with 25% overlap. Instrumental output sums the three nonvocal model estimates. Both outputs are stereo 44.1kHz float WAV, with unchanged sample count and finite samples checked by the worker. The caller supplies normalized input and a fresh output directory. One directory rename publishes the completed pair. Cancellation terminates the worker and removes staging output; it does not modify source audio.

The first preparation downloads about 84.1 MB (80.2 MiB) to the application model cache; subsequent preparation verifies and reuses the checkpoint offline. An invalid cached file fails with `model_checksum_mismatch`; it is never loaded or silently replaced. The caller can remove the corrupt cache entry and retry. Cache paths and application permissions are supplied by the engine, not by the model registry.

Execution and format validation do not establish separation quality, SDR, latency for full tracks, or subjective audio quality. The development audit uses a five-second read-only excerpt and records its own elapsed time; no benchmark score is claimed.
